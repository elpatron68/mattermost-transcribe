# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

Report security issues affecting this plugin through one of:

1. **GitHub Security Advisories** (preferred):  
   [https://github.com/medisoftware/mattermost-transcribe/security/advisories/new](https://github.com/medisoftware/mattermost-transcribe/security/advisories/new)

2. **Email:** security@medisoftware.de

Include a description, steps to reproduce, and affected versions if known. We aim to acknowledge
reports within a few business days.

For vulnerabilities in Mattermost Server itself, follow Mattermost's process:
[responsibledisclosure@mattermost.com](mailto:responsibledisclosure@mattermost.com).

## Scope

This policy covers the **mattermost-transcribe** plugin only. Parakeet ASR is a separate
self-hosted service — report Parakeet issues to its upstream project.
