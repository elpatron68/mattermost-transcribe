# Screenshots for README and Marketplace

Add PNG screenshots here before submitting to the Mattermost Marketplace. Embed them in the root
[README.md](../../README.md) once captured.

## Required captures

| File | What to show |
|------|----------------|
| `message-input-microphone.png` | Channel view with the microphone button visible next to the file upload icon |
| `recording-overlay.png` | Recording in progress (timer + level meter visible) |
| `review-dialog.png` | Review dialog with sample transcript, **Send** and **Discard** buttons |

## Tips

- Use the Mattermost **web or desktop** app (mobile is not supported).
- Use a test channel; blur or fake usernames if needed.
- Recommended width: **1280 px** or wider; PNG format.
- Hide sensitive channel content.

## Marketplace web form

The [Marketplace submission form](https://developers.mattermost.com/integrate/marketplace-submissions/)
also asks for a **512×512** listing icon (PNG, JPG, or SVG). Export from
[`assets/icon.svg`](../../assets/icon.svg) or create a dedicated `marketplace-icon-512.png`.

## After adding files

1. Add image references under **Screenshots** in `README.md`.
2. Check off the screenshot items in [MARKETPLACE.md](../MARKETPLACE.md).
